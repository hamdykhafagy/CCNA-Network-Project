# CCNA Enterprise Network Project

## Overview
This project demonstrates the design and implementation of a complete enterprise network infrastructure using Cisco networking technologies. The environment was built to simulate a real-world enterprise network and covers switching, routing, network services, security, and centralized management.

## Objectives
- Configure Cisco routers and switches with secure basic settings.
- Implement VLAN segmentation and inter-VLAN communication.
- Configure Dynamic Host Configuration Protocol (DHCP) for automated IP address assignment.
- Implement dynamic routing using EIGRP.
- Secure remote administration using SSH.
- Configure RADIUS-based authentication.
- Apply Access Control Lists (ACLs) to enforce security policies.
- Deploy and test network services in a multi-router environment.

## Technologies Used
- Cisco IOS
- VLANs
- Rapid Spanning Tree Protocol (RSTP)
- DHCP
- EIGRP
- SSH
- RADIUS Authentication
- Access Control Lists (ACLs)
- Cisco Packet Tracer

## Network Features

### Switching
- VLAN creation and port assignment.
- Rapid STP implementation.
- Trunk configuration between switches.

### Routing
- Inter-VLAN routing.
- Dynamic routing using EIGRP.
- Default route configuration between routers.

### Network Services
- DHCP pools for multiple VLANs.
- DNS configuration for clients.

### Security
- SSH-only remote access.
- Password encryption.
- User authentication using RADIUS.
- ACL implementation to restrict access to specific services and resources.

- Troubleshooting connectivity and service issues.
- Configuring Cisco devices in a multi-site environment.
